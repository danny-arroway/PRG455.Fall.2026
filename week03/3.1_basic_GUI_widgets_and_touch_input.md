### 1. Why M5UI, Not Tkinter

Tkinter is a desktop GUI library — it depends on a full operating
system windowing layer and the complete CPython standard library. The
CoreS3 runs **MicroPython**, a stripped-down interpreter with no
windowing system underneath it; it drives its screen directly over SPI.
There is no `tkinter` module, and there's no practical way to add one
on a microcontroller with this little RAM and flash.

**M5UI** is the framework that actually runs on the device, built on
top of **LVGL** (Light and Versatile Graphics Library). Conceptually
it's close to Tkinter — widget objects, positioning, event callbacks —
but the syntax and the specific widget set are different, and this
course's labs use **only** the widgets covered in lecture, never free
text entry (the on-screen keyboard is too fragile to rely on for
graded work).

### 2. The M5UI Programming Model

Every M5UI program follows the same skeleton:

```python
import os, sys, io
import M5
from M5 import *
import m5ui
import lvgl as lv

page0 = None

def setup():
    global page0
    M5.begin()
    Widgets.setRotation(1)     # landscape
    m5ui.init()                # must be called before creating any widgets
    page0 = m5ui.M5Page(bg_c=0xFFFFFF)

    # ... create widgets here, all with parent=page0 ...

    page0.screen_load()        # actually display the page

def loop():
    M5.update()                 # pumps touch and the UI redraw

if __name__ == '__main__':
    try:
        setup()
        while True:
            loop()
    except (Exception, KeyboardInterrupt) as e:
        try:
            m5ui.deinit()
            from utility import print_error_msg
            print_error_msg(e)
        except ImportError:
            print("please update to latest firmware")
```

Two things to internalize immediately:

- **`m5ui.init()` before any widget is created**, and every widget you
  create should be given `parent=page0` so it belongs to the page you
  load.
- **`M5.update()` must run every loop iteration**, or touch input stops
  being processed and the screen stops redrawing.

### 3. Widget Reference

#### 3.1 `M5Label` — displaying text

**A gotcha before we start:** LVGL fonts are compiled into the firmware
at specific sizes to save flash space. `font_montserrat_14` is always
present, but larger sizes (18, 20, 24, ...) are optional and vary by
firmware build. Using a size that isn't compiled in causes an
`AttributeError` the moment the widget is created — not a warning, a
crash. Look the font up defensively and fall back to the one size
that's always there:

```python
title_font = getattr(lv, "font_montserrat_24", lv.font_montserrat_14)

title_label = m5ui.M5Label(
    "PRG455 Lecture 3",
    x=10, y=10,
    text_c=0x000000,      # text color
    bg_c=0xFFFFFF,         # background color
    bg_opa=0,               # 0 = transparent background
    font=title_font,
    parent=page0,
)
```

Use `getattr(lv, "font_montserrat_N", lv.font_montserrat_14)` any time
you reach for a font size other than 14.

Labels are read-only text, but their content isn't static — any
label's text can be changed at runtime with `set_text()`:

```python
title_label.set_text("Status: Ready")
```

This is how you'll show live feedback: you don't redraw the whole
screen, you just update the one label that changed.

#### 3.2 `M5Button` — triggering actions

```python
calculate_button = m5ui.M5Button(
    text="Calculate", x=10, y=190, w=140, h=32,
    bg_c=0x2196F3,
    text_c=0xFFFFFF,
    font=lv.font_montserrat_14,
    parent=page0,
)

def calculate_button_clicked(event_struct):
    result_label.set_text("Done!")

def calculate_button_handler(event_struct):
    if event_struct.code == lv.EVENT.CLICKED:
        calculate_button_clicked(event_struct)
    return

calculate_button.add_event_cb(calculate_button_handler, lv.EVENT.ALL, None)
```

One handler function per widget, registered with `add_event_cb`, which
dispatches based on `event_struct.code`. You'll use this exact shape
for every interactive widget in this course.

#### 3.3 `M5Slider` — picking a value from a range

A slider is a natural fit any time the user needs to choose one value
out of a small, ordered set — not just a continuous quantity. This
course uses sliders for both: a genuinely continuous setting, *and* as
a stepped selector across a short list of named options (in which case
the slider's integer position indexes into a Python list).

```python
size_slider = m5ui.M5Slider(
    x=10, y=48, w=300, h=18,
    mode=lv.slider.MODE.NORMAL,
    min_value=0, max_value=2, value=0,
    bg_c=0x115E9F, color=0x2C90E4,
    parent=page0,
)
```

Reading the current position is `size_slider.get_value()`. Setting it
programmatically (for a Reset button, for example) needs **two**
arguments — a value and an animate flag — not one:

```python
size_slider.set_value(0, lv.ANIM.OFF)
```

Leaving out the second argument is a `TypeError`, not a silent
no-op — LVGL's slider API is consistent about this across the widget
set, and it's an easy thing to forget.

**Driving a label from a slider** is the pattern you'll lean on
heavily in Lab 3 — a slider alone just shows a bare position number, so
you pair it with a label that translates that position into something
readable:

```python
SIZES = ["Small", "Medium", "Large"]

def size_slider_changed(event_struct):
    index = size_slider.get_value()
    size_label.set_text("Size: " + SIZES[index])

def size_slider_handler(event_struct):
    if event_struct.code == lv.EVENT.VALUE_CHANGED:
        size_slider_changed(event_struct)
    return

size_slider.add_event_cb(size_slider_handler, lv.EVENT.ALL, None)
```

#### 3.4 Raw Touch — going underneath the widgets

Every widget event you've used so far is really built on top of one
thing: the touch controller reporting where a finger is on the glass.

```python
def loop():
    M5.update()
    if M5.Touch.getCount():
        x = M5.Touch.getX()
        y = M5.Touch.getY()
        print("Touched at:", x, y)
```

You won't need this for most UI work — the widget event system handles
the coordinate math for you — but it's the right tool for custom
drawing or gestures.

### 4. The Overflow Trap (learn this now, not the hard way)

Here's a bug that's easy to write and easy to miss until it's live in
front of students. `M5Label` has no `w` or `h` parameter at all — unlike
`M5Button` or `M5Slider`, a label isn't given a box; it just draws its
text starting at `(x, y)` and grows to fit, with nothing clipping it.

```python
# DON'T do this without checking your longest possible string first:
result_label = m5ui.M5Label("", x=10, y=216, parent=page0)
result_label.set_text(some_long_formula_generated_string)
```

That has two ways to fail. If the string is one long unwrapped line, it
just keeps drawing rightward — off the right edge of the 320px screen,
with no wrapping or clipping to save you. If you *do* wrap it into
multiple lines but placed the label too close to the bottom of the
240px-tall screen, the lower lines run straight off the bottom edge,
because there's no box height to push back against.

Two things fix this together:

1. **Wrap long text yourself**, rather than trusting it'll fit:

```python
def wrap_text(text, max_chars_per_line=36):
    words = text.split(" ")
    lines = []
    current = ""
    for word in words:
        candidate = (current + " " + word).strip()
        if len(candidate) <= max_chars_per_line:
            current = candidate
        else:
            if current:
                lines.append(current)
            current = word
    if current:
        lines.append(current)
    return "\n".join(lines)

result_label.set_text(wrap_text(long_message))
```

2. **Budget real screen space for the wrapped result** — if your
   longest message wraps to two lines, your result label needs room
   for two lines (roughly 40px at this font size), positioned with
   enough clearance above the 240px bottom edge, not squeezed into
   whatever space was left over after everything else was laid out.

Work out your longest possible generated string *before* you place the
result label, not after.

### 5. Full Worked Example: Pizza Order Estimator

Three sliders drive three live-updating labels; a Calculate button
runs a small pricing formula and displays the result (wrapped safely);
a Reset button puts everything back to its starting state. This is the
same shape Lab 3 uses — sliders driving labels, a formula-driven
result, a reset — applied to a different scenario.

```python
# SPDX-License-Identifier: MIT
#
# PRG455 Lecture 3 -- Pizza Order Estimator
# Demonstrates M5Label, M5Button, and M5Slider (as both a continuous
# control and a stepped selector), with safe text wrapping.

import os, sys, io
import M5
from M5 import *
import m5ui
import lvgl as lv
 
ANIM_OFF = getattr(lv, "ANIM_OFF", 0)
 
page0 = None
title_label = None
size_label = None
size_slider = None
toppings_label = None
toppings_slider = None
delivery_label = None
delivery_slider = None
calculate_button = None
reset_button = None
result_label = None
 
SIZES = ["Small", "Medium", "Large"]
BASE_PRICE = [8.00, 11.00, 14.00]
TOPPING_PRICE = 1.50
DELIVERY_FEE = 3.00
DELIVERY_OPTIONS = ["Pickup", "Delivery"]
 
 
def wrap_text(text, max_chars_per_line=36):
    words = text.split(" ")
    lines = []
    current = ""
    for word in words:
        candidate = (current + " " + word).strip()
        if len(candidate) <= max_chars_per_line:
            current = candidate
        else:
            if current:
                lines.append(current)
            current = word
    if current:
        lines.append(current)
    return "\n".join(lines)
 
 
def size_slider_changed(event_struct):
    size_label.set_text("Size: " + SIZES[size_slider.get_value()])
 
 
def size_slider_handler(event_struct):
    if event_struct.code == lv.EVENT.VALUE_CHANGED:
        size_slider_changed(event_struct)
    return
 
 
def toppings_slider_changed(event_struct):
    toppings_label.set_text("Toppings: %d" % toppings_slider.get_value())
 
 
def toppings_slider_handler(event_struct):
    if event_struct.code == lv.EVENT.VALUE_CHANGED:
        toppings_slider_changed(event_struct)
    return
 
 
def delivery_slider_changed(event_struct):
    delivery_label.set_text("Order: " + DELIVERY_OPTIONS[delivery_slider.get_value()])
 
 
def delivery_slider_handler(event_struct):
    if event_struct.code == lv.EVENT.VALUE_CHANGED:
        delivery_slider_changed(event_struct)
    return
 
 
def calculate_button_clicked(event_struct):
    size_index = size_slider.get_value()
    toppings = toppings_slider.get_value()
    delivery_index = delivery_slider.get_value()
 
    price = BASE_PRICE[size_index] + toppings * TOPPING_PRICE
    if delivery_index == 1:
        price += DELIVERY_FEE
 
    message = "%s pizza, %d toppings, %s: $%.2f" % (
        SIZES[size_index], toppings, DELIVERY_OPTIONS[delivery_index], price,
    )
    result_label.set_text(wrap_text(message))
 
 
def calculate_button_handler(event_struct):
    if event_struct.code == lv.EVENT.CLICKED:
        calculate_button_clicked(event_struct)
    return
 
 
def reset_button_clicked(event_struct):
    size_slider.set_value(0, ANIM_OFF)
    toppings_slider.set_value(0, ANIM_OFF)
    delivery_slider.set_value(0, ANIM_OFF)
    size_label.set_text("Size: Small")
    toppings_label.set_text("Toppings: 0")
    delivery_label.set_text("Order: Pickup")
    result_label.set_text("")
 
 
def reset_button_handler(event_struct):
    if event_struct.code == lv.EVENT.CLICKED:
        reset_button_clicked(event_struct)
    return
 
 
def setup():
    global page0, title_label
    global size_label, size_slider, toppings_label, toppings_slider
    global delivery_label, delivery_slider
    global calculate_button, reset_button, result_label
 
    M5.begin()
    Widgets.setRotation(1)
    m5ui.init()
    page0 = m5ui.M5Page(bg_c=0xFFFFFF)
 
    title_font = getattr(lv, "font_montserrat_20", lv.font_montserrat_14)
    title_label = m5ui.M5Label(
        "Pizza Order Estimator", x=10, y=4,
        text_c=0x000000, bg_c=0xFFFFFF, bg_opa=0,
        font=title_font, parent=page0,
    )
 
    size_label = m5ui.M5Label(
        "Size: Small", x=10, y=30,
        text_c=0x000000, bg_c=0xFFFFFF, bg_opa=0,
        font=lv.font_montserrat_14, parent=page0,
    )
    size_slider = m5ui.M5Slider(
        x=10, y=50, w=300, h=16,
        mode=lv.slider.MODE.NORMAL,
        min_value=0, max_value=2, value=0,
        bg_c=0x115E9F, color=0x2C90E4, parent=page0,
    )
    size_slider.add_event_cb(size_slider_handler, lv.EVENT.ALL, None)
 
    toppings_label = m5ui.M5Label(
        "Toppings: 0", x=10, y=76,
        text_c=0x000000, bg_c=0xFFFFFF, bg_opa=0,
        font=lv.font_montserrat_14, parent=page0,
    )
    toppings_slider = m5ui.M5Slider(
        x=10, y=96, w=300, h=16,
        mode=lv.slider.MODE.NORMAL,
        min_value=0, max_value=5, value=0,
        bg_c=0x115E9F, color=0x2C90E4, parent=page0,
    )
    toppings_slider.add_event_cb(toppings_slider_handler, lv.EVENT.ALL, None)
 
    delivery_label = m5ui.M5Label(
        "Order: Pickup", x=10, y=122,
        text_c=0x000000, bg_c=0xFFFFFF, bg_opa=0,
        font=lv.font_montserrat_14, parent=page0,
    )
    delivery_slider = m5ui.M5Slider(
        x=10, y=142, w=300, h=16,
        mode=lv.slider.MODE.NORMAL,
        min_value=0, max_value=1, value=0,
        bg_c=0x115E9F, color=0x2C90E4, parent=page0,
    )
    delivery_slider.add_event_cb(delivery_slider_handler, lv.EVENT.ALL, None)
 
    calculate_button = m5ui.M5Button(
        text="Calculate", x=10, y=168, w=140, h=32,
        bg_c=0x2196F3, text_c=0xFFFFFF,
        font=lv.font_montserrat_14, parent=page0,
    )
    calculate_button.add_event_cb(calculate_button_handler, lv.EVENT.ALL, None)
 
    reset_button = m5ui.M5Button(
        text="Reset", x=160, y=168, w=140, h=32,
        bg_c=0x757575, text_c=0xFFFFFF,
        font=lv.font_montserrat_14, parent=page0,
    )
    reset_button.add_event_cb(reset_button_handler, lv.EVENT.ALL, None)
 
    result_label = m5ui.M5Label(
        "", x=10, y=204,
        text_c=0x000000, bg_c=0xFFFFFF, bg_opa=0,
        font=lv.font_montserrat_14, parent=page0,
    )
 
    page0.screen_load()
 
 
def loop():
    M5.update()
 
 
if __name__ == '__main__':
    try:
        setup()
        while True:
            loop()
    except (Exception, KeyboardInterrupt) as e:
        try:
            m5ui.deinit()
            from utility import print_error_msg
            print_error_msg(e)
        except ImportError:
            print("please update to latest firmware") 
```

Notice the result label sits at `y=204` — deliberately chosen to leave
roughly 36px of clearance before the 240px bottom edge, enough for the
two wrapped lines `wrap_text` produces from the longest message this
program can generate. There's no `h` to set; the only thing holding the
text on screen is that `y` position being chosen with the worst case in
mind, not placed on autopilot.

### 6. Key Takeaways

- M5UI, not Tkinter, is what runs on the CoreS3 — same widgets-and-
  events mental model, different library, and no free text entry in
  this course's labs.
- `getattr(lv, "font_montserrat_N", lv.font_montserrat_14)` — always,
  for any size other than 14.
- `slider.set_value(value, lv.ANIM.OFF)` takes two arguments; leaving
  the animate flag off is a `TypeError`, not a no-op.
- Pair every slider with a label that translates its numeric position
  into something readable, updated via a `VALUE_CHANGED` handler.
- Work out your longest possible result string, wrap it deliberately,
  and budget real screen space for the wrapped result *before* you
  place the label — not after it clips off the bottom of the screen.
