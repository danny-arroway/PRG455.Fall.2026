# Week 3 — Basic GUI Widgets and Touch Input

**Lecture:** Sept 24 · **Lab:** Sept 21

## Lecture Topic

Basic GUI widgets and touch input: Label, Button, and Slider — the first of six lectures
(Weeks 3–8) that each pair one Core S3 hardware capability with the M5UI widget used to work
with it.

## This Week's Materials

| File | Covers |

## Lab Activity — Lab 3: Local AI GPU Advisor

Build a single-screen M5UI application on the Core S3 with three sliders (each paired with a
live-updating label), a Recommend button that computes a GPU recommendation from the sliders
using the required VRAM formula, and a Reset button that returns everything to its starting
state. Touch-only operation, wrapped result text with no clipping.
