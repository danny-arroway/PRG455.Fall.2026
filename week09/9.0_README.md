## Lab Activity — Lab 8: Connectivity-Driven Interface (Dropdown Control)

Build a multi-stage touchscreen application on the Core S3: a manually-created
`.credentials.sys` file (SSID + password) is encrypted in place by a small
Claude Code-built utility using a passphrase entered at encryption time; the
main app then scans for Wi-Fi networks with `wlan.scan()`, populates an
`M5Dropdown` with the results, decrypts the stored password using a
hardcoded passphrase constant, and connects using the guarded
`safe_connect()` pattern from Lecture 9. Once connected, the screen switches
to a quote-fetcher: a bordered 200×200 text area, a red "Get Quote" button
that fetches and displays text from a fixed URL (wrapping as needed, never
accumulating across presses), and a red "Disconnect" button that ends the
Wi-Fi session and displays a centered completion message.

**This week's lab is also the first to make deliberate use of agentic AI**
via Claude Code, per `9.2_agentic_AI_and_Claude_Code.md` — read that file
before starting, in addition to the lecture material. The lab spec itself
is structured as three separate agentic tasks (encryption utility, network
selector, quote fetcher), each documented separately in `PROMPTS.md`.
