# Week 2 — MicroPython and the Core S3

**Lecture:** Sept 17 · **Lab:** Sept 14

## Lecture Topic

MicroPython and the Core S3: flashing UIFlow2 firmware, connecting via the UIFlow2 web editor,
and running code with Run Once.

## Lab Activity — Lab 2

Flash the Core S3 with the course-standard firmware, connect it to the UIFlow2 web editor, and
verify serial output (`heartbeat.py`), display output (`display_test.py`), and a basic IMU
sensor read (`imu_test.py`) using Run Once.
