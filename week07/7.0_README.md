## Lab Activity — Lab 6: Microphone Sound Level Meter & Word Counter

Build a single-screen M5UI application on the Core S3 with an LED that
continuously reflects ambient sound level (via the required peak-amplitude and
clamp-and-scale formula), a live percentage label updating in step with the
LED, a running word count (blue background, white text) driven by a
silence-gap detection state machine, and a sensitivity switch that toggles
between Normal and Sensitive interpretation of the microphone signal. No
buttons — the LED, percentage label, and word count all update on their own,
every pass through `loop()`, with the switch changing behaviour immediately on
toggle.
