## Lab Activity — Lab 7: Speaker-Driven Interface (Spinbox Control)

Build a single-screen M5UI application on the Core S3 with a frequency
spinbox (range 100–5000 Hz, step 10, starting at 440), a live frequency label
that updates immediately on every spinbox change, a Play button that plays
the currently selected frequency through the speaker for a fixed 300ms, and
a status label that tracks playback state. This lab is almost entirely
event-driven — the one exception is a `loop()`-driven check of
`Speaker.isPlaying()`, needed because `Speaker.tone()` itself does not block.
