## Self-check before submission

**Part A**
- Required header block present, complete, no placeholders
- Snapshot button labelled exactly "Snapshot"
- Countdown displays 5,4,3,2,1,0, one per second, in order
- Photo captured at the instant `0` is displayed
- Saved as exactly `/flash/photo.jpg`, positional `jpg.encode()` quality,
  binary write mode, wrapped in `try`/`except`
- `photo.jpg` successfully retrieved and present in `labTest1/partA/`

**Part B**
- Required header block present, complete, no placeholders
- Title reads exactly "About Me"
- All three sliders' labels update correctly and immediately, in both
  directions, across their full range
- `about_me.md` contains the 10-field header, all three slider selections
  in words, and a reference to `photo.jpg`, in that order
- MAC address in the generated file is obtained programmatically from the
  device, not hand-typed, and verified to match the device's actual MAC
- `about_me.md` successfully retrieved and present in `labTest1/partB/`
- No two widgets overlap at any point, in either part
- `PROMPTS.md` present and current if AI assistance was used, in either part
