# Week 5 — The Camera and Visual Feedback

**Lecture:** Oct 8 · **Lab:** Oct 5

## Lecture Topic

The camera and visual feedback: the Image widget — the third of six lectures
(Weeks 3–8) that each pair one Core S3 hardware capability with the M5UI
widget used to work with it.

## Lab Activity — Lab 5: Camera Snapshot Panel

Build a single-screen M5UI application on the Core S3 with a live camera
preview drawn via `M5.Lcd.show()`, a Capture button that saves the current
frame as a JPEG to flash and displays it in an `M5Image` widget, a Clear
button that reverts the display to a placeholder image, and a status label
that accurately reflects whether a photo has been captured. Touch-only
operation, no overlap between the live preview and any other widget on
either axis.

- Status label always accurately reflects captured/not-captured state
